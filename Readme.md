
# gogetway

中文 | [English](Readme_EN.md)

## 介绍: 

gogetway是一款开源的能支持TCP流量的高性能流量录制网关，适用于录制TCP流量，支持自定义级别的TCP流量回放，
适用于HTTP1.0-HTTP2.0协议、WebSocket、SSH等基于TCP的协议


## 特别鸣谢

本项目接入LINUXDO公益站进行部分开发,感谢[LINUXDO](https://linux.do/)社区支持

## 特性:

1. 可作为库直接进行二次开发，我们提供完整的开发接入文档(文档在做)
2. 已提供 release 页面中的 `tcp-proxy` 二进制文件，支持开箱即用的代理、录制与回放
3. 占用超低的CPU和内存

## 适用场景:

1. 对于蜜獾服务器可使用其进行原始的流量记录，便于溯源、审计
2. 对于CTF练习题目，可进行流量录制，方便复现
3. 对于线上灰度测试、流量监测，可进行流量录制，方便测试
4. 可捕捉SSH协议等非常规的TCP流量，利于监控审计
5. 可支持服务熔断功能开发，对于异常流量可直接拦截，进行熔断处理

## tcp-proxy 二进制文件用法:

`tcp-proxy` 支持常见的代理、录制、回放与被动镜像能力。

### 1. 代理并录制流量

```bash
./tcp-proxy -l :9000 -f 127.0.0.1:8080 -o ./traffic.log
```

含义:
- `-l`: 本地监听地址
- `-f`: 转发目标地址
- `-o`: 输出录制文件

### 2. 回放录制文件到指定服务

```bash
./tcp-proxy -r -f 127.0.0.1:8080 -o ./traffic.log
```

含义:
- `-r`: 开启回放模式
- `-f`: 回放目标服务地址
- `-o`: 录制文件路径

### 3. 只监听/镜像并记录流量

```bash
./tcp-proxy -l 8090 -io -o ./mirror.log
```

该模式不会占用被监听服务本身的端口，适合对指定端口进行被动镜像记录。

### 4. 镜像并转发到指定服务

```bash
./tcp-proxy -l 8090 -f 127.0.0.1:18090 -o ./mirror.log
```

## 注意事项:

1. 使用 `-io` 被动监听/镜像功能时，Windows 需要安装 `Npcap`，Linux 需要安装 `libpcap`
2. 使用 `-io` 时，建议以具备抓包权限的用户身份运行程序
3. 不使用 `-io` 时，可直接使用代理录制和回放功能
